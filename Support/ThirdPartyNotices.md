# Microsoft Speech SDK

The app includes the official Microsoft Cognitive Services Speech SDK for macOS, version 1.52.0, from https://github.com/microsoft/speech-sdk-spm/tree/1.52.0.

The SDK is distributed under its own Microsoft license, not the license of this application. The original LICENSE.md and ThirdPartyNotices.md accompanying the official SDK are copied into the app's Contents/Resources directory at build time. No SDK logging or audio logging is enabled by this application.
