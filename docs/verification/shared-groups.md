## 界面核对

使用临时独立预览 app 与 `/tmp/office-groups-preview-data/` 下的数据和独立 UserDefaults；没有操作用户实际数据库，没有调用 AI 服务。模型支持指定独立数据目录，并在该模式下跳过提醒调度。

核对通过：

- 1040 宽窗口下一级组显示 3 条待办（1 条直属、2 条子组），二级组显示 2 条；行显示实时完整分组路径。
- 原生侧栏展开一级组后可选择二级组；分组编辑窗口对已有子组的父组禁用调整上级。
- 从二级组新建待办，表单预选“客户 A → 项目一”。
- 二级组会议列表只显示该组会议；打开会议可查看原文与已有纪要，保留删除、导出及相关待办入口。
- 删除一级组的确认框明确显示同时移除 1 个子组，会议、纪要和待办保留。界面核对取消最终删除；实际删除语义由自动测试验证。
- 空分组显示 0 项及新增入口说明；900 宽窗口下筛选、分段切换、新建按钮及事项列表可用。
- 故意损坏测试目录文件后，侧栏显示“分组暂时不可用 / 重试读取分组”，原待办仍可查看且不会被误标为未分组；恢复测试文件并点击重试后正常显示原分组路径。
