## 使用限制与工程取舍

- 暂存音频只在进程内保留，退出/崩溃会丢失尚未定稿的内容；字幕独立持久化。音频默认不落盘。
- Azure/听悟只提供实时入口。断线暂存可以放弃后继续；补处理入口只对支持文件识别的 OpenAI/硅基流开放，不静默切换服务。
- 文件恢复匹配采用大小及首尾各 64 KiB 摘要，不是整文件内容校验；同大小且只修改中间部分不能检出。恢复到最后已确认偏移，未定稿部分重新处理。
- 录音选择不跨进程保存。重启后中断录音的旧字幕可读，新录音需新建会议重新选音源。
- 真正退出/睡眠会停止本次采集；听悟远端关闭在无网络时可能失败，保存任务 ID 与待清理状态供手动关闭。若创建任务的 HTTP 响应丢失，客户端可能无法得知任务 ID，需到听悟控制台核查。
- 模型列表不提供可靠的统一能力元数据，界面提示模型能力仍需验证，不自动替换服务。WebSocket 使用官方 URLSession 连接，Azure 通过官方 SDK，测试分别采用协议事件/桥接及控制器模拟。
- 未启用时不会上传待办。阶段 C 的会议纪要、自动 Todo、导出尚未实现。
