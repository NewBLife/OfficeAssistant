## 范围与质量限制

DeepSeek和硅基流的纪要仅模拟传输验证，未用真实凭证调用；Azure/听悟只负责识别，不是纪要提供方。macOS14及实时硬件链路仍未新增实机验证。本阶段真实链路为OpenAI文件转写和纪要，不代表其他服务通过。
