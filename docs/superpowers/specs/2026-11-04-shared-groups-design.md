# 两层共用分组设计

日期：2026-11-04。状态：用户已于 2026-11-04 审阅通过。

## 目标与已确认规则

按客户或项目统一整理会议、会议纪要及待办。共用一套最多两层的分组，例如“客户 A → 项目一”。

- 会议和待办各归属零个或一个分组，一级、二级分组均可直接存放内容。
- 纪要及其历史版本跟随来源会议，不独立移动。
- 一级分组汇总本组及全部二级分组；二级分组只显示自身内容。
- 支持新建、重命名、移动和删除分组；现有记录默认归入“未分组”。
- 从会议创建新待办时默认继承会议分组，之后可独立调整。
- 删除分组需确认，只删除分组结构，内容归入“未分组”。删除一级分组时同时移除其二级分组，确认框明确列出影响范围。
- 保留现有会议、音频、纪要、待办、完成状态、提醒及相互来源关系。分组为本机功能，不调用 AI。

## 方案取舍

推荐：独立分组目录，加会议与待办上的可选分组标识。分组层级集中校验，归属随原有记录保存；不改变两个现有 Core Data 数据库的实体结构。

其他可选方案：把所有归属另存一张映射表，虽不改记录字段，但会使新增、重复待办和删除多一处同步；将两个数据库迁入同一数据库可提供跨模块事务，但迁移范围明显超过本功能需要。首版采用推荐方案。

## 数据与兼容

- OfficeCore 新增 `WorkGroup`：稳定 UUID、名称、可选 `parentID`。不存冗余层级数字。
- `TaskItem` 与 `MeetingSession` 新增可选 `groupID: UUID?`。旧版 JSON 缺少字段时解码为 nil，无需重写历史记录。纪要不增加分组字段。
- 分组目录存于 `~/Library/Application Support/OfficeAssistant/groups.json`，包含格式版本和分组数组。与现有任务、会议库一起备份。
- 文件不存在视为初次使用、空目录；读取失败、格式版本不支持、结构损坏均保留原文件并禁用分组写入，显示可重试错误，不用空目录覆盖。
- 每次保存先校验完整快照，原子替换文件；磁盘写入成功后才更新内存。失败时界面保留原结果。
- 空名称、同一父级下重名（忽略首尾空白及大小写）、重复标识、缺失父级、循环、自身为父级及第三层均拒绝。不同父级允许同名。名称最长 80 个字符，拒绝控制字符；“全部内容”“未分组”为保留名称。
- 删除分组采用一次目录快照更新。记录中的旧 groupID 无法解析时按“未分组”处理，不要求跨数据库批量改写。删除父分组会在同一次更新中移除所有子分组。新保存的记录将无效归属规范化为 nil。
- 移动一级分组至另一一级下时，仅无子分组者可移动；有子分组者必须先移动子组，避免隐式生成第三层。二级分组可移至其他一级或提升为一级。

## 界面与操作

- 主侧栏保留“今天”“全部待办”“已完成”“会议记录”“AI 服务”“设置”，新增可展开的“分组”区域，包含“全部内容”“未分组”、一级及二级分组和新增入口。
- 点击具体分组打开分组工作区，以“待办 / 会议与纪要”切换。初始显示待办。会议内容继续复用已有会议详情和纪要页签，不复制纪要。
- 分组工作区显示完整路径、搜索和新增入口。待办支持全部、待处理、进行中、已完成筛选，会议可按标题搜索。筛选、空状态与统计口径一致。
- 一级视图包含其子组，行上显示实际归属路径；路径展示使用当前分组名称，重命名立即更新。
- 分组菜单提供新增子组（仅一级）、重命名、移动及删除。移动使用目标选择器，不要求实现拖拽。删除确认说明子组一并删除、记录保留。
- 新建待办、新建会议及音频导入表单增加分组选择器。从具体分组新建默认选择该分组；从“全部内容”“未分组”及原有入口新建默认未分组。保存前仍可调整。
- 待办编辑及菜单、会议详情及列表菜单提供移动分组，包含“未分组”选项；已完成待办也可移动，不影响完成状态。会议正在录音、导入或收尾时禁止移动当前会议，保持现有会话保存边界。
- 从待办跳转来源会议时，保证打开目标会议，即使它不属于当前筛选分组；不因分组筛选隐藏导航目标，也不停止另一场正在记录的会议。
- 空目录提示先创建分组；空分组提供新增待办及会议入口。组目录读取失败时仍允许查看原有待办和会议，但分组区域显示不可用，不把它们误显示为“未分组”。

## 业务集成

- 分组规则集中在 OfficeCore；持久化及可观察状态由 OfficeDesktop 的 GroupStore 负责，由 OfficeAppModel 持有并注入相关视图、任务服务及会议服务。
- TaskStore 提供独立移动归属操作，支持已完成记录。重复待办生成下一实例时继承当前分组；撤销完成的实例比较需包含分组字段。
- MeetingSessionController 负责会议分组保存，并同步当前会话和历史列表，不直接在视图中改写仓库。
- 行动项校对创建页默认使用来源会议的有效分组；用户可修改。关联已有待办只增加来源关系，保留该待办原分组。
- 行动项创建重试沿用已有任务及其分组，不能把用户后来移动的待办移回来源会议分组。候选状态保存失败时仍沿用原有防重复逻辑。
- 分组变动不改变原文、纪要版本和 AI 配置，不影响纪要内容指纹。删除或移动分组不删除会议、音频或待办，不调用云端。

## 验证与交付

- 规则测试：两层创建、父组汇总、名称校验、改名、移动、循环与第三层拒绝、删除父组及子组、失效归属回退。
- 持久化测试：原子保存与失败保留、损坏/未知版本阻止覆盖、重开后保留层级、旧版待办与会议 JSON 兼容。
- 集成测试：创建默认归属、会议生成待办继承及用户覆盖、关联已有待办不改变归属、重试保留归属、已完成及重复待办分组、会议移动限制、删除分组后内容保留、来源导航跨分组可达。
- 界面核对：两层侧栏、父组聚合、分组切换、编辑和删除确认、空状态与错误状态。使用独立测试数据，避免修改用户现有记录。
- 执行 `bash scripts/test.sh`，通过后执行 `bash scripts/build-app.sh`。保留既有删除会议和导出音频修复。生成包含最新应用的 Apple Silicon DMG，验证镜像、签名、程序一致性与 Applications 安装入口。
- 支持平台沿用 Apple Silicon、macOS 14+；不新增第三方依赖，不修改凭证和网络配置。

## 范围边界

首版不含第三层分组、多分组归属、标签、云同步、团队权限或自动 AI 分类。分组内会议纪要仍使用现有会议详情，不新增跨会议汇总。
