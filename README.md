# 办公助手

Mac 中文桌面办公助手，当前版本 **0.3.0**。包含本机待办、完成标记和提醒，会议收音、音频导入、转写与中日商务字幕翻译，以及会议纪要、行动项审阅、会议与待办双向关联、纪要导出。云端功能可在应用中配置各自凭证；已用OpenAI合成样本验证文件转写、纪要生成、待办关联与导出，具体服务及质量边界见文末验证记录。

## 打开与开始使用

双击 `dist/OfficeAssistant.app`。关闭主窗口后应用保留在菜单栏；点击清单图标可以重新打开或新增待办。“退出办公助手”才会退出程序。

会议功能首次使用请先打开左侧“AI 服务”，选择服务，在安全输入框中录入凭证并保存。已有凭证不会回填，保存成功后输入框清空；密钥只存系统钥匙串，不写进会议库、设置文件或日志。不需要在聊天里发送密钥。

识别与翻译分别选择，默认 OpenAI 识别、DeepSeek 翻译。修改模型后点击“保存 AI 设置”。模型列表检查只代表该账号能读取列表；模型是否支持对应功能、是否有访问权限，仍以实际调用为准。不会自动换服务或账号。

| 服务 | 实时语音 | 文件识别 | 文字翻译 | 需要填写 |
|---|---|---|---|---|
| OpenAI | 流式 | 支持 | 支持 | API Key |
| DeepSeek | — | — | 支持 | API Key |
| 硅基流 | 短片段连续识别 | 支持 | 支持 | API Key |
| 微软 Azure Speech | 官方 SDK 连续识别 | — | — | Speech 资源密钥、对应区域 |
| 阿里通义听悟 | 实时任务推流 | — | — | AccessKey ID、AccessKey Secret、听悟项目 AppKey；可选 STS Token |

微软和听悟需要各自已开通的服务。普通百炼 API Key 不能代替听悟凭证；前三家的 API Key 也不能代替微软或听悟凭证。

## 会议与翻译

- 创建会议或导入音频时，可选择“仅转写”或“转写并翻译”。仅转写只要求识别服务凭证，不读取翻译密钥、不发送翻译请求，界面只显示原文；校对原文也不会触发翻译。可在 AI 服务中设置默认模式，已有会议保持原来的模式。
- 识别语言可单独选择中文、日语或中日混合，与是否翻译分开设置。
- “会议记录 → 新建会议”：填写标题、参与者备注，选择识别服务、翻译服务、日译中或中译商务日语。可显式启用中日混合识别，其实际效果需要样本验证。
- 面对面场景选择麦克风；线上会议场景点击“读取可用的会议音源”，选择具体会议软件或显示器，也可同时录入麦克风。系统可能请求音频录制权限。建议使用耳机以减少重复收音。
- 开始后音频发送到所选识别服务；已定稿原文和有限上下文发送到所选翻译服务。原文、译文分区显示，并标注音源。音源标签不代表发言人身份。
- 支持系统可解码的 WAV、M4A、MP3、AIFF 等音频导入，识别服务选择 OpenAI 或硅基流。文件分块处理，不一次加载整段录音。
- 暂停、停止、系统睡眠和输入设备中断会阻断新的音频发送。停止时未处理的尾部不会自动补传，可显式点击“处理未完成片段”或“放弃暂存”。Azure/听悟只接实时输入，当前暂存补处理限 OpenAI/硅基流；这些实时服务可以放弃暂存后继续记录。
- 原文先保存，再送翻译；翻译失败可以单独重试，也可编辑原文后重新翻译。重试保留原会议的服务与方向，使用 AI 服务中这家服务当前保存的翻译模型。全局术语表在 AI 服务中以“原词=译法”逐行维护。
- 断网或处理积压时最多保留 60 秒待处理音频，达到上限暂停。暂存只在进程内保留，退出会丢失尚未定稿的暂存；已定稿字幕保存在本机。
- 中断的文件导入可以重新选择原音频，校验大小及首尾摘要后，从最后已确认位置继续。选择不同文件会拒绝续传。录音设备选择不跨重启保存，重启后不会自动开始录音；新的录音请重新选择音源。
- 听悟需要关闭云端任务。网络异常时页面会显示“清理待关闭的听悟云端任务”，联网后手动重试。凭证过期可在停止记录后更新原账号凭证，再清理；不要把只关闭窗口当作任务已结束。

关闭主窗口可以继续记录，菜单栏有录音状态及停止入口。退出应用会中断记录。实时字幕存在网络和模型延迟，硅基流在片段结束后才开始识别。当前只有 OpenAI 的单个合成样本结果，尚无实时链路延迟或通用准确率数据。

## 会议纪要与相关待办

打开会议后，选择“转写 / 会议纪要 / 相关待办”页签。

- 暂停或结束记录后，在“会议纪要”点击“生成会议纪要”。仅转写会议也可生成，不需要开启实时翻译。每次可独立选择 OpenAI、DeepSeek 或硅基流、模型、中文或中日双语。
- 导入音频的实际会议日期默认未知。只有你确认实际日期后，程序才尝试解析“明天下午三点”等具体时间；“下周”“明天下午”等模糊时间仍需确认，不会自动设置提醒。
- 纪要包含概述、议题摘要、明确决定、未解决问题和行动项。每个要点/行动项附原文引文，可点击回到来源片段。音源标签不代表具体发言人；不确定负责人留空。
- 行动项先进入候选区，核对后选择“校对并加入待办”或“关联已有待办”；也可忽略。可能重复、承诺不明确或分段生成的候选需要逐项确认，不能直接批量加入。长会议和会议中提取需查看全场后续是否取消或变更了事项。
- “相关待办”显示任务库的实际完成状态，可完成、撤销、新建、关联已有任务（含已完成）或解除会议关系。解除关系保留待办本身。待办上的会议来源按钮可回到原文；另一场会议正在记录时不会自动停止它。
- 待办加入后可独立修改。重新生成不会改写已加入任务，也不会因任务删除或解除关联而自动重建。任务保存成功而候选状态更新失败时，重试沿用已保存任务。
- “编辑纪要”保存新版本；生成新版本也保留历史。原文或纪要在生成期间变化时，该结果会被拒绝，旧记录保留。取消/重启不自动重新发送请求。完整重新生成会替换未加入的候选，保留已加入事项。
- 可选“会议中提取行动项”，默认关闭；新增至少5个最终片段、距上次至少60秒时处理新增原文，只生成候选。暂停/停止会关闭提取。它不能代替结束后核对整场会议。
- “导出纪要”支持中文/中日双语 Markdown（.md）和 UTF-8 纯文本（.txt），自行选择保存位置。包含所选纪要版本、行动项实际状态与来源引文，不默认附整份转写。导出完全使用本地内容；缺少双语版本时需先明确生成，不会在导出时自动调用翻译。日文行动项标为原始版本，中文任务改动后需核对其对应翻译。

一次纪要最多处理24万字，按每块最多12000字顺序生成，整体限10分钟、行动项最多100条；超过会明确提示。长会议分段摘要需人工核对跨段前后变更。Word/PDF、跨会议汇总和自动对外发送尚未提供。

## 待办与提醒

- 点击“新增待办”填写标题；快捷记录可识别“明天下午三点交周报”等时间表达，检查表单后保存。模糊时间保留原文，等待补充。
- 点击左侧圆圈完成；在“已完成”中再次点击可以撤销。重复事项完成后生成下次实例，不回补错过的所有周期。
- “今天”显示当天到期和逾期任务，单列无日期事项；“全部待办”支持搜索、筛选和编辑。
- 任务菜单可开始处理、稍后 10 分钟提醒或删除。删除需再次确认。设置中可填写姓名，新增时点击“我”。

首次点击“开启提醒”后允许系统通知。默认每天 09:00（Asia/Shanghai）发送今日汇总入口通知，可调整时间、时区或关闭。到期通知提供“完成”和“10 分钟后提醒”，系统可能需要展开通知才能看到按钮。

关闭主窗口不影响调度。默认最多安排最近 48 条到期通知，应用运行时每分钟及唤醒时继续补充；真正退出后不会继续补充，已交给系统的通知仍由系统调度。大量任务建议保留菜单栏运行，也可手动开启登录时启动。

关机、睡眠、专注模式或通知设置会影响展示；重新打开后仍可查看遗漏事项。任务日期按所属时区显示，更换时区保持同一绝对时刻。

## 本机数据与音频

数据目录：`~/Library/Application Support/OfficeAssistant/`。待办存于 `tasks.store`，会议独立存于 `meetings.store`；设置由系统偏好保存，凭证由系统钥匙串保存。待办不会作为会议内容自动发送给云端。

默认不保留原始音频。新建会议时勾选“在本机保留原始音频”，则分音源保存 WAV 到 `Audio/`；导入音频时也可勾选，保存原文件副本，原始导入文件不会修改。暂停或停止记录后，点击会议页“导出音频”选择保存目录，程序会新建一个会议文件夹并分别复制所有音源文件。未保留原始音频的旧会议无法从字幕还原录音。

会议详情或列表右键菜单可选择“删除会议”，确认后删除会议、转写、纪要、候选行动项及生成历史，已加入的待办保留；可勾选同时删除本机音频。正在记录时需先暂停或停止，听悟任务未关闭时需先清理云端任务。录音可能包含敏感内容，保留与清理由你决定。当前未提供音频自动删除周期。异常断电时最后一个 WAV 的文件头可能未完成收尾。

备份前先退出应用，再复制整个 OfficeAssistant 目录，不要只复制使用中的单个数据库。读取失败会保留原文件并阻止覆盖，不要直接清空目录作为恢复手段。
